# Simulador Cuantitativo de Trading

Simulador de capital y gestión de riesgo basado en modelos probabilísticos (con enfoque en ratio 1:3, gestión del 1% por operación y análisis de drawdown). Diseñado como una Progressive Web App (PWA) para acceso rápido desde el iPhone.

## 🚀 Características
* **Gestión de Riesgo:** Simulación estricta basada en el modelo de pérdida controlada del 1% por trade.
* **Parámetros Ajustables:** Control deslizante para Capital Inicial, Win Rate, Ratio Riesgo:Beneficio y Días de Operativa.
* **Visualización Gráfica:** Curva de capital en tiempo real comparada con la expectativa teórica mediante Chart.js.
* **Optimizado para Móvil:** Interfaz oscura construida con Tailwind CSS, diseñada para fijarse como aplicación en la pantalla de inicio del celular.

## 🛠️ Stack Tecnológico
* HTML5
* Tailwind CSS (CDN)
* Chart.js (CDN)
* GitHub Pages (Hosting)

## 📱 Uso en iPhone
1. Visita el sitio desplegado en GitHub Pages.
2. Abre la página en Safari.
3. Presiona el botón de **Compartir** y selecciona **"Agregar a la pantalla de inicio"**.
